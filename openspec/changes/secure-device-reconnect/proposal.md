# 安全的账号设备绑定与断线恢复

## 问题

公网配对当前把采集端 WebSocket 与查看端恢复令牌绑定在内存房间中。采集端短暂断网或应用重启会销毁房间，桌面端丢失凭据，网页只能重新输入新配对码。现有网页恢复令牌只在同一浏览器保存，不能从账号恢复已登记的设备。

## 目标

- 用户用账号和密码登录网页；首次输入配对码时将采集电脑绑定到该账号。
- 绑定后配对码作为稳定设备标识，不再单独授予访问权；已登录账号可从设备列表连接，无需再次输入配对码。
- 采集端凭据在本机加密保存，应用重启、网络恢复或中继重启后自动认证；网页与采集端各自使用有界退避重连。
- 断线期间保留账号/设备绑定与网页授权；在线截图和配置仍只经 WSS 临时转发，不保存到服务器磁盘。

## 非目标

- 迭代 1 不部署线上服务、不构建/分发安装包；该迭代已完成。迭代 2 经用户明确授权，构建本机 Windows 安装包并更新线上网页/中继。
- 不保证电脑关机、休眠或断网时继续采集；不实现远程唤醒、组织/团队权限、邮箱验证、第三方登录或密码找回。
- 不把截图、模型配置、API Key、提示词或对话保存到服务器。

## 安全设计

- 账号密码使用带随机盐的 scrypt 哈希保存；登录/注册限速，错误登录不泄露用户名是否存在。
- 浏览器会话令牌使用高熵随机值，仅保存哈希；仅通过 `Secure; HttpOnly; SameSite=Strict; Path=/` Cookie 传递。修改状态的 HTTP 请求校验同源 `Origin` 和会话 CSRF 令牌，WebSocket 校验同源来源。
- 稳定配对码只作设备标识。首次认领需要有效账号会话和仍在有效期内的配对码；认领后不能再通过配对码直接进入。查看端必须是设备所属账号。
- 采集端使用独立 256 位随机设备密钥；服务端只存哈希，桌面端通过 Electron `safeStorage` 加密后原子写入用户数据目录。账户登出不影响采集端服务；账号可撤销单台设备。
- 服务端只持久化账号哈希、会话哈希、设备归属/稳定码/密钥哈希；活动截图和配置不进入持久化存储。状态文件权限限制为服务账户可读写，并通过原子替换避免半写入。
- 未授权、撤销、坏口令、来源不匹配、过期会话和被撤销设备均拒绝连接；手动退出设备会撤销设备并关闭活动连接。

## 允许范围

`server/relay.js`、新增服务端认证/状态存储模块、`server/public/index.html`、`server/public/viewer.css`、`server/public/viewer.js`、`server/public/workbench.js`、`main.js`、`preload.js`、`renderer/index.html`、`renderer/renderer.js`、`renderer/styles.css`、关联测试、README 和本变更 OpenSpec。迭代 2 另外允许更新线上中继、上述网页资源及 systemd 状态目录配置；不改 Nginx、Docker、其他站点，不推送 Git 或上传桌面安装包。

## 验收

- 相同账号只能查看自己认领的设备；未知账号、错误密码、伪造来源、跨站请求、旧会话和撤销设备均不能访问。
- 配对首次成功后设备码不变；网页刷新、换同账号浏览器或网络短断后自动连接，不要求再次输入配对码。
- 采集端在网络波动、应用重启和中继重启后使用原设备凭据恢复；仅停止共享/撤销设备时才删除稳定绑定。
- 服务重启后用户、设备和授权哈希仍在；截图/配置不落盘。
- 本机 `npm.cmd run check`、`npm.cmd test` 和 `git diff --check` 通过；迭代 2 还需完成发布后健康、静态资源、未登录端点及状态目录权限检查。

## 授权、发布边界与回滚

- approval: 用户于 2026-10-17 先授权实现安全断线恢复并暂缓线上更新；之后明确要求“网页上更新，本地安装包也更新”，授权构建本机安装包并部署线上网页/中继。
- 发布边界：生成 `dist/release-0.4.4/` 下的本机 Windows x64 安装程序与 ZIP；更新线上中继、四个网页资源和 systemd unit。不得推送 Git、上传安装包、改 Nginx/Docker 或其他站点。
- 回滚：部署前备份并校验旧版 `relay.js`、四个网页资源及 systemd unit。失败时停止服务并逐项恢复这些文件；旧版原无 `security-store.js` 时移除新增文件，恢复 unit 后 daemon-reload 并启动旧服务。保留新建的 `/var/lib/screenbridge` 认证状态目录及其中数据，不删除或覆盖。
- 部署影响：重启中继会断开现有连接；旧配对不会迁移为账号设备。更新后需安装新版、注册/登录并首次绑定；绑定完成后才可自动恢复。
- 部署前置：状态目录 `/var/lib/screenbridge` 由服务账号拥有且权限为 `0700`；更新后检查 systemd 语法与状态、HTTPS 健康端点、关键网页资源、未登录端点和状态目录权限。
