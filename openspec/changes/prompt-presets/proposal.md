# 为截图回答和追问增加可管理的提示词预设

## 问题

截图回答提示词和追问输入目前只能手动输入，没有办法保存常用写法；每次使用相同要求都需要重新填写。

## 目标

为“告诉模型怎么答”和追问输入框分别提供独立的提示词预设列表。用户可以新增、选择载入、更新和删除预设；列表保存在本机配置中，数量不设上限。

## 范围

- 将两类预设及其名称、内容保存在应用本地配置中。
- 在两个对应的输入区域提供预设选择和管理操作。
- 更新模型配置时保留提示词预设。
- 更新 README 使用说明。

## 非目标

- 不改变模型系统提示词、截图分析或追问请求格式。
- 不同步预设到其他设备或云端。
- 不限制提示词预设数量。

## 验收

- 截图回答和追问各自维护独立预设列表。
- 用户可以新增并保存预设，选择后载入对应输入框，并可更新或删除。
- 重启后预设仍可从本机配置载入；保存模型设置时预设不丢失。
- 存储与界面均不会截断提示词预设列表数量。
- `npm run check` 与 `git diff --check` 通过，新增界面控件 ID 均有对应脚本引用。
