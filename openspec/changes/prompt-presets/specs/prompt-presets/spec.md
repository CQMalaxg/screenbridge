# 提示词预设

## 需求：分别管理回答与追问提示词

应用 MUST 为截图回答提示词和追问提示词提供相互独立的预设列表。每条预设包含唯一标识、名称和提示词文本。

### 场景：新增提示词预设

- **当** 用户在任一输入框填写提示词并新增预设
- **那么** 应用保存名称与当前输入内容
- **并且** 保存后该预设出现在对应列表中

### 场景：使用、更新或删除预设

- **当** 用户选择一个预设
- **那么** 应用将预设文本载入对应的输入框
- **当** 用户更新选中预设或删除选中预设
- **那么** 应用只修改对应类型的预设列表，并将结果保存到本机配置

## 需求：本地持久化且不限制数量

应用 MUST 将提示词预设保存在本机配置中，并在读取或保存模型设置时完整保留预设。预设列表 MUST NOT 被应用侧的固定数量上限截断。

### 场景：重启后载入

- **当** 用户重新启动应用
- **那么** 已保存的回答和追问预设仍可分别选择和管理

### 场景：保存大量预设

- **当** 任一类型保存超过常见固定数量上限的预设
- **那么** 应用保存并载入完整列表，已有条目不会因列表长度被丢弃
