# 公网配对采集电脑与浏览器

## 问题

现有共享通过局域网 HTTP 端口提供画面，远程浏览器无法越过 NAT/防火墙直连采集电脑，也没有多用户隔离。

## 目标

采集端主动连接公网中继并生成短期配对码；持有配对码的浏览器可以经 HTTPS 请求实时截图。每个会话独立、限时，画面只在内存转发，不写入服务器。

## 非目标

- 不提供账户注册、长期设备目录、录制、回放或云端截图存储。
- 不改变现有模型、截图批次、提示词预设或局域网共享行为。
- 不让浏览器访问采集电脑的公网/局域网端口。

## 验收

- 多台采集电脑可各自创建不同配对码；错误码、过期码及非配对会话不能取图。
- 浏览器经 TLS 连接；采集端只向外连接中继；截图按请求传输且不落盘。
- 服务端限制配对码尝试频率和单房间连接数，房间到期后释放资源。
- 现有 Nginx 网站和容器保持可用，新增入口可以单独回滚。
- `npm run check`、中继单元/集成检查及部署后 HTTPS/配对往返检查通过。

## 授权与回滚

- 回滚：停止并禁用本项目专属 systemd 服务；移除本项目专属 Nginx 站点片段并执行配置测试/平滑 reload；删除本项目专属 `/opt/screenbridge` 文件。保留原有站点、容器、数据和其它配置；桌面端可回退到当前工作区修订。

## 后续迭代：完整浏览器工作台

当前线上页面只有配对与查看一张画面，缺少桌面端的截图批次、模型设置、提示词预设和分析追问流程。本迭代将这些核心操作加入响应式网页，并保留采集端主动连接、按需取图和截图不落盘的边界。

- 行为目标：查看设备可以在网页完成配对、多张截图管理、模型/提示词设置、截图分析、连续追问和重试。
- 非目标：网页直接采集平板或浏览器设备的操作系统屏幕；账户系统或云端保存模型密钥、截图、对话与预设。
- 本机数据：设置与提示词预设保存到当前浏览器；API Key 默认只在当前页面内存中，用户勾选后才保存在该浏览器。
- 模型调用：由浏览器直接请求用户配置的模型服务；模型服务需允许来自工作台域名的跨域请求，失败时给出具体排查提示。中继不接触模型密钥和分析请求。
- 移植方式：直接复用桌面端 `renderer/index.html`、`renderer/styles.css` 与渲染层的截图、模型配置、预设和会话代码；只为浏览器替换 Electron 专属采集/IPC接口并增加公网配对入口。
- 验收：所有核心桌面工作流可在桌面和移动浏览器完成；截图可多张添加/选择/删除；预设数量不限；流式分析/追问可停止、清空、复制和重试；本机检查与公网工作台验证通过。
- 回滚：保留桌面端和已部署配对协议；恢复旧网页静态资源并重载专属中继服务即可。

## 后续迭代：配对成功后保持长连接

- 目标：配对码只限制首次连接时限；浏览器成功加入后，只要浏览器与采集端仍连接，房间就不会因 15 分钟计时而结束。
- 行为：未使用的配对码仍在创建 15 分钟后失效。首次查看端成功连接即进入活动会话；关闭/断开任一端或采集端点击停止共享时，立即撤销房间与配对码。
- 非目标：永久设备配对、断开后自动保留房间、账户系统、截图或模型数据持久化。
- 验收：活动会话跨过原配对码有效期仍可正常取图；未连接的过期码仍被拒绝；活动房间中第二个查看端仍被拒绝；任一端断开后另一端收到断开提示，旧码不能再连接。
- 回滚：恢复 `/opt/screenbridge/server/backups/browser-workbench-20261010-1/predeploy.tar.gz` 中的服务器文件并重启专属中继；Windows 用户可重装之前生成的 `屏桥 ScreenBridge Setup 0.4.0.exe`。
- approval: 用户于 2026-10-10 明确要求“只要连接就不会断开，除非浏览器或者本地断开”；沿用此前用户对该服务器部署屏桥的授权。
