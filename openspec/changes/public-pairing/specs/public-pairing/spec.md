# 公网配对与截图转发

## 需求

- 采集端创建一组随机、限时配对凭据，并通过出站安全连接注册到中继。
- 查看者在 HTTPS 浏览器页面输入配对码；只有有效房间可建立一个查看连接。
- 查看者明确请求画面后，采集端捕获一次屏幕并经中继直接发送给查看者；中继不得持久化截图。
- 每位用户的采集端拥有独立房间。无效配对码、过期房间、重复查看者与异常大画面均被拒绝。
- 房间及画面仅驻留内存；服务重启后已创建的配对码失效。
- 本机局域网共享方式仍可用。

## 验收场景

- 两组不同配对码可分别连接各自采集端；每个浏览器只收到所属设备截图。
- 错误/过期配对码收到明确失败状态且无法访问截图。
- 配对码尝试超过频率限制时被限速。
- 采集端断开或服务重启后，查看页报告连接中断，不显示旧缓存画面。
- 浏览器与中继所有公网数据均通过 HTTPS/WSS。

## 长时间会话

- 配对码的 15 分钟有效期只约束查看端首次加入；成功配对后，活动会话不再按该时限自动断开。
- 活动会话在采集端与查看端保持连接期间持续有效；任一端断开、采集端停止共享或中继服务结束会话时，房间与旧配对码立即失效。
- 活动房间仍只允许一个查看端；配对码不能用于查看其他用户的房间。
