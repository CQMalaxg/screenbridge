# 浏览器工作台

## 需求

- 首次使用配对码后，网页获得独立的随机恢复凭据并保存在当前浏览器；网页刷新、重新打开或网络暂时中断时自动恢复原会话，无需操作仍在线的采集电脑。
- 活动配对中，查看网页断开不会关闭采集连接或撤销配对会话；只有持有恢复凭据的网页可以重连，原配对码不能重复加入或接管会话。
- 查看者手动断开时清除本地恢复凭据并结束配对；采集端停止、断开或中继会话丢失时，恢复凭据不再有效。
- 配对查看者可以从已连接的采集电脑按需连续截取多张画面；每张截图均可预览、切换和单独删除，也可清空整个批次。只有明确点击分析后，截图才发送给所选视觉模型。
- 查看者可独立配置视觉模型和对话模型。每组支持多个可命名预设、默认模型、协议、服务地址、模型名称和 API Key；每次分析/追问前可直接选择本次使用的模型，失败不再按优先级顺延。
- 浏览器可管理截图回答和后续追问两组提示词预设，数量不设上限。选择预设后输入框立即载入其文字；用户可新增、更新或删除预设。
- 查看者可用所选视觉模型对当前截图批次发起流式分析，可停止请求、换模型后复用截图批次重试、复制回答及清空对话。
- 成功分析后查看者可进行多轮追问；历史回答随追问发送，可选择附带当前截图；可停止生成、复制回答或清空当前对话。
- 查看者选中回答中的文字时，工作台在选区附近显示更大字号的预览；选区清除、离开回答内容或视窗变化后关闭预览。
- 点击分析后，待分析截图栏立即清空；本轮截图在当前页面内保留，以支持失败后重试和追问时选择附图。
- Responses API 追问把用户消息编码为 `input_text`、助手历史回答编码为 `output_text`，并保持附加截图使用 `input_image`；模型拒绝请求时仍展示 HTTP 状态和服务端错误详情。
- 截图和会话上下文只在当前页面内存中。设置与提示词预设保存在当前浏览器。API Key 默认不持久化；只有查看者明确启用此浏览器保存后才写入本机浏览器存储。
- 模型请求由浏览器直接发往用户配置的服务。中继不接收模型密钥、截图分析请求或追问内容；模型服务需允许工作台网页跨域请求。
- 桌面和窄屏浏览器均能完成配对、截图管理、模型设置、分析和追问；按钮具有明确状态和错误说明。

## 场景

### 连续添加和分析多张截图

- 假设查看者已连接采集电脑且已配置可用视觉模型，当查看者连续请求截图并选择“分析 N 张截图”，则工作台依次从采集端取图并将所选截图作为同一次模型输入。
- 假设配对断开或截取失败，当查看者请求新截图，则不增加损坏条目并显示可理解的错误。

### 管理模型与提示词预设

- 假设查看者创建多个模型或提示词预设，当数量继续增长，则所有已保存预设仍可选择、编辑和删除。
- 假设查看者选择提示词预设，则对应编辑框立即替换为预设内容。
- 假设查看者刷新网页，则截图与对话不恢复，已保存设置和提示词预设仍保留在此浏览器。
- 假设查看网页刷新或短暂断网，且采集电脑仍连接中继，则当前浏览器使用已保存恢复凭据自动重连；采集电脑不需重启或重新生成配对码。
- 假设查看网页失去恢复凭据，则短期配对码不能再次加入已经建立的会话；采集端停止或中继丢失会话后旧恢复凭据被拒绝。
- 假设查看者在网页手动断开，则本地恢复凭据被清除，采集端收到结束配对并撤销房间。

### 分析与连续追问

- 假设当前有截图且视觉模型已配置，当开始分析，则仅请求所选模型，显示增量响应和实际模型状态；失败直接显示该模型错误，不调用其他预设。
- 假设采集端同步了多个模型，当查看者在追问框选择其中一个模型，则本次追问使用对应地址、协议、密钥和模型，且继续携带已有对话历史；选择不覆盖采集端配置。
- 假设仍存在手动选中的预设，当采集端更新模型配置，则选择保持；选中的预设被删除时，下拉框显示新的默认选项，后续请求与可见选项一致。
- 假设正在生成内容，当查看者停止请求，则网络请求终止并保留已收到文本。
- 假设已有成功分析，当查看者提交追问，则已完成的对话历史用于生成回答；截图仅在查看者勾选附带截图时再次发送。
- 假设模型接口不允许浏览器跨域请求，则工作台说明需在模型服务端启用相应跨域访问或检查网络，而不把模型密钥/内容转发到屏桥中继。
- 假设查看者选中一段助手回答，则预览在选区附近以较大字号显示所选内容；点击回答区域外或取消选择时预览关闭。
- 假设查看者点击分析截图，则所有待分析缩略图和预览立即从截图栏清除；请求失败或被停止时仍可重试刚才的截图批次。
- 假设查看者使用 Responses API 继续对话，则用户消息使用 `input_text`，历史助手回答使用 `output_text`，附图继续使用 `input_image`；其他 HTTP 400 错误应保留并显示模型服务返回的诊断文本。
