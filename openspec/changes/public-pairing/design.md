# 设计：浏览器完整工作台

## 决策

直接移植桌面端工作区、样式、截图批次、模型/提示词预设、对话历史和错误回退流程，并让浏览器提供桌面端 IPC 接口的适配层。这样用户沿用同一套操作和行为，只有系统采集/共享的调用点因浏览器环境改为公网配对取图。

网页直接连接用户配置的模型服务。这样模型 API Key、截图和对话内容不会经过或保存在中继服务器；密钥默认只留在当前页面内存，用户可选择保存在当前浏览器。模型预设、提示词预设与其他工作台设置保存在浏览器本机。

模型服务必须允许工作台域名的浏览器跨域请求。遇到跨域或网络错误时，网页说明需要检查模型服务的浏览器跨域支持和当前设备网络。浏览器使用设备当前网络设置；网页无法使用桌面端独立配置的 HTTP 代理。

## 边界

- 中继仍只做短期配对和按请求转发截图，不新增 AI API 转发，不接收模型 API Key。
- 浏览器关闭/刷新后，截图和会话上下文清空；模型与提示词预设留在浏览器本机。
- 本迭代回滚只需恢复 `server/public/` 的静态文件，不改变配对协议或桌面端。
