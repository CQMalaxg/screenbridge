# macOS 桌面版适配

## 问题

桌面端目前只有 Windows 安装目标，自动启动、截图授权提示和应用图标也沿用 Windows 行为，Mac 用户无法获得可直接安装且操作明确的版本。

## 目标

提供可在 Intel 与 Apple 芯片 Mac 上安装的通用版 DMG/ZIP，并让桌面端的截图、公网恢复、菜单栏驻留和登录启动符合 macOS 行为。

## 范围

- 增加 macOS 通用包构建配置及手动 GitHub Actions 构建流程。
- 适配 macOS 登录启动、菜单栏图标和窗口关闭/恢复行为。
- 在没有屏幕录制授权时显示明确的系统设置指引。
- 更新追问快捷键提示与 README 中的桌面平台说明。

## 非目标

- 不更改网页、服务器、配对协议或模型配置行为。
- 按用户本轮要求，将 macOS 适配提交推送至独立 GitHub 功能分支；不合并主分支、不发布 Release、不部署服务器。
- 本次不配置 Apple Developer 签名或公证；安装说明需解释首次打开的系统提示。

## 验收条件

- macOS runner 能生成同时支持 Intel 与 Apple 芯片的 DMG 和 ZIP 构建产物。
- 有屏幕录制权限时沿用现有截图流程；权限缺失时给出可执行的系统设置指引。
- 登录启动、窗口关闭后驻留、从菜单栏或 Dock 恢复窗口均有对应平台行为和自动化测试。
- Windows 现有行为通过回归测试，README 说明构建与首次打开限制。

`f59b62e`；Windows 本地环境。当前 57 项测试及 `npm.cmd run check` 通过；工作区另有未提交的网页多设备切换修复，本变更不包含该修复。
