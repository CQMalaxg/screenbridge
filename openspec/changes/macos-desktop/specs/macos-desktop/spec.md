# macOS 桌面版行为

## 需求

### 需求：安装包

macOS 用户必须能从通用 DMG 或 ZIP 安装屏桥桌面端；同一产物支持 Intel 与 Apple 芯片。构建过程不得自动发布版本或更改线上服务。

#### 场景：在 macOS runner 构建

- 当维护者手动运行 macOS 构建流程时，流程生成 DMG 与 ZIP 构建产物并供下载。
- 若没有 Apple 签名与公证凭据，文档必须说明首次打开时 macOS 可能要求用户确认。

### 需求：屏幕录制授权

桌面端必须遵循 macOS 屏幕录制授权。没有可用画面时，错误信息必须指导用户在“系统设置 → 隐私与安全性 → 屏幕录制”允许屏桥并重新启动应用。

#### 场景：已授权

- 当用户已允许屏幕录制时，截图与现有截图分析流程正常工作。

#### 场景：未授权或已拒绝

- 当系统未提供可用屏幕画面时，应用保留现有截图并显示授权设置指引，不把问题误报成模型或网络错误。

### 需求：菜单栏与窗口生命周期

macOS 桌面端必须提供可辨识的菜单栏图标；关闭主窗口后应用继续运行，用户可从菜单栏或 Dock 重新打开窗口，显式退出仍会停止应用。

### 需求：登录启动

用户启用登录启动后，macOS 登录时应用应在后台启动并恢复已保存的公网设备连接；设置界面必须反映平台支持状态。

### 需求：Mac 快捷键

追问输入框的帮助文字必须同时说明 macOS 的 Command+Enter 和 Windows/Linux 的 Ctrl+Enter；两个按键组合都能发送追问。
