# 截图批次

## ADDED Requirements

### Requirement: 采集截图时保持应用窗口稳定

应用 MUST 在本机截图时避免隐藏并重新显示主窗口，且 MUST 在截图期间保持窗口焦点不变。

#### Scenario: 添加本机截图

- **WHEN** 用户点击“添加截图”
- **THEN** 截图包含助手窗口下方的屏幕内容，但不包含助手窗口自身
- **AND** 助手窗口不经历隐藏/显示或重新聚焦造成的可见闪烁

### Requirement: 连续收集并检查截图

应用 MUST 允许用户连续添加屏幕截图，并在分析前查看当前截图批次。用户 MUST 能切换预览批次中的图片、删除单张图片或清空整个批次。

#### Scenario: 添加多张截图

- **WHEN** 用户多次点击添加截图
- **THEN** 每次成功采集的画面都会加入当前批次，且不会覆盖之前的图片
- **AND** 用户可以辨认批次中的图片数量和当前预览项

#### Scenario: 删除或清空截图

- **WHEN** 用户删除批次中的一张图片
- **THEN** 其余图片仍保留，预览切换到有效的剩余图片
- **WHEN** 用户清空截图
- **THEN** 批次变为空，分析和重试不可用

### Requirement: 将截图批次作为同一问题发送

应用 MUST 将当前批次中的所有图片与同一段提问一起交给视觉模型。重试 MUST 复用本次分析所用的全部图片。追问仅在用户勾选“附带当前截图”时附上当前批次的所有图片。

#### Scenario: 分析与重试

- **WHEN** 当前批次至少有一张图片且用户开始分析
- **THEN** 视觉模型请求包含批次中的全部图片和提问文本
- **WHEN** 用户重试本轮分析
- **THEN** 重试请求包含相同的全部图片

#### Scenario: 追问附图

- **WHEN** 用户勾选附带截图并发送追问
- **THEN** 对话模型请求包含当前批次中的全部图片
- **WHEN** 用户未勾选附带截图
- **THEN** 对话模型请求不包含图片

### Requirement: 兼容现有单图请求

主进程 MUST 接受包含单张图片的现有请求格式，也 MUST 接受包含一张或多张图片的新格式。无有效图片的视觉分析请求 MUST 失败并显示可理解的错误。

#### Scenario: 接收单图或多图请求

- **WHEN** 主进程收到现有单图字段或新多图字段
- **THEN** 请求中有效图片均被作为图片内容交给对应模型

#### Scenario: 拒绝空分析

- **WHEN** 视觉分析请求没有有效图片
- **THEN** 请求失败并提示用户重新添加截图
