# 任务：支持一次分析多张截图

## 范围锁

- 目标：用户可收集多张截图，并在一轮视觉分析中发送整批图片。
- 非目标：图片导入、持久化、编辑、视频、截图数量限制、局域网协议变更。
- 允许范围：`main.js`、`preload.js`、`renderer/index.html`、`renderer/renderer.js`、`renderer/styles.css`、`README.md`、本变更目录。
- 已知基线：`npm run check` 通过；仓库无 UI 自动化测试。

## 任务

- [x] **1.1** [DONE] 完成截图批次的收集、检查、分析、重试和追问闭环。
  - 完成条件：可添加/预览/删除/清空多张截图；视觉分析和重试发送全部图片；追问按勾选状态附带全部图片；主进程保留单图兼容。
  - 允许文件：范围锁中列出的源码、README 和变更契约文件。

  - 必需验收：语法检查通过；有界自审确认所有图片发送路径与空批次处理符合规格。
