# 支持一次分析多张截图

## 问题

当前截图流程每次只保留一张图片，后续截图会覆盖之前的图片，视觉模型与追问模型也只收到单张图片。

## 目标

用户可以连续添加多张本机或远程屏幕截图，检查、删除或清空截图后，将剩余截图与同一段提示词一起发送给视觉模型分析。采集时应用窗口保持可见，不触发隐藏/显示带来的闪烁。

## 范围

- 允许在 `renderer/`、`main.js`、`preload.js` 和 README 中修改截图队列、预览、模型请求与使用说明。
- 视觉模型重试复用本轮全部截图；追问勾选附图时发送当前截图队列。
- 模型请求同时兼容单张旧字段与新的多图字段。
- 单机采集时将助手窗口排除在系统截图之外，保持窗口可见和焦点稳定。

## 非目标

- 不增加本地图片导入、截图编辑/标注、持久化图库、视频采集或截图数量上限。
- 不改变局域网共享与设备发现行为。

## 验收

- 每次点击添加截图只增加一张；预览能切换查看并可单独删除。
- 分析与重试向视觉模型发送队列中全部图片；无截图时不能提交分析。
- 追问勾选附图时附上当前全部图片；未勾选时仍只发文本。
- 清除可清空截图队列；现有单图请求仍可被主进程接受。
- 点击“添加截图”时窗口不隐藏/重现，不出现闪烁。

## 基线

- `npm run check` 在提交 `6a63333` 上通过。
- 仓库没有现成 UI 或自动化测试；OpenSpec CLI 未预检。
