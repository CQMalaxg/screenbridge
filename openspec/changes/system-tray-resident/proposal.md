# 关闭窗口后驻留系统托盘

## 问题

点击窗口右上角关闭会退出屏桥并断开正在使用的配对。用户希望关闭窗口后把程序收进 Windows 通知区域，稍后继续使用。

## 目标

关闭主窗口时隐藏到托盘并保持应用及配对运行；用户可从托盘重新打开窗口，或通过托盘菜单明确退出。

## 非目标

- 不增加开机自启、自动更新或托盘通知。
- 最小化按钮仍按 Windows 默认行为最小化到任务栏。

## 允许范围

`main.js`、`tray-lifecycle.js`、`package.json`、`package-lock.json`、`test/`、`openspec/changes/system-tray-resident/`。

## 验收

- 点击窗口关闭后，窗口隐藏，屏桥进程和配对会话继续运行。
- 点击托盘图标或选择“显示屏桥”可恢复窗口。
- 选择托盘菜单中的“退出屏桥”会真正结束进程并停止共享。
- 新版 Windows 安装包包含托盘图标与行为。

## 基线

0.4.1 关闭窗口会退出应用。变更前 `npm.cmd run check` 通过，`npm.cmd test` 13/13 通过。
